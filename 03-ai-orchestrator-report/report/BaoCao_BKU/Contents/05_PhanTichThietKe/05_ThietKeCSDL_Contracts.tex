\section{Thiết kế Cơ sở Dữ liệu \& Hợp đồng Giao tiếp Dữ liệu (Data Engineering)}
\label{sec:thiet_ke_csdl}

Hệ thống tuân thủ nguyên lý Kỹ nghệ Hợp đồng Dữ liệu (Contract-Driven Engineering): Mọi luồng giao tiếp giữa các vi dịch vụ và các tác tử AI đều phải được kiểm định kiểu tĩnh thông qua các lược đồ Pydantic v2 và DDL quan hệ chuẩn hóa.

\subsection{Lược đồ Cơ sở Dữ liệu Quan hệ (Relational Schema -- PostgreSQL 16)}
\label{subsec:relational_ddl}

Hệ thống triển khai 4 bảng cốt lõi phục vụ lưu trữ tồn kho, giữ chỗ giao dịch và hồ dữ liệu:

\begin{lstlisting}[language=SQL, caption={Đặc tả DDL Cơ sở Dữ liệu PostgreSQL}]
-- 1. BANG TON KHO CHUYEN XE THOI GIAN THUC
CREATE TABLE bus_trips (
    trip_id VARCHAR(50) PRIMARY KEY,
    operator_name VARCHAR(100) NOT NULL,
    origin VARCHAR(50) NOT NULL,
    destination VARCHAR(50) NOT NULL,
    bus_type VARCHAR(50) NOT NULL,
    departure_time VARCHAR(10) NOT NULL,
    arrival_time VARCHAR(10) NOT NULL,
    fare_vnd BIGINT NOT NULL,
    available_seats INTEGER NOT NULL CHECK (available_seats >= 0),
    pickup_point VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. BANG TON KHO PHONG KHACH SAN
CREATE TABLE hotel_rooms (
    room_id VARCHAR(50) PRIMARY KEY,
    hotel_name VARCHAR(100) NOT NULL,
    location VARCHAR(255) NOT NULL,
    room_type VARCHAR(50) NOT NULL,
    price_per_night BIGINT NOT NULL,
    available_rooms INTEGER NOT NULL CHECK (available_rooms >= 0),
    checkin_standard VARCHAR(10) DEFAULT '14:00',
    early_checkin_fee BIGINT DEFAULT 0,
    pet_allowed BOOLEAN DEFAULT FALSE,
    policy TEXT NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. BANG GIAO DICH GIU CHO TAM THOI (ACID HOLDING - TTL 15 PHUT)
CREATE TABLE reservations (
    reservation_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id VARCHAR(100) NOT NULL,
    trip_id VARCHAR(50) REFERENCES bus_trips(trip_id),
    room_id VARCHAR(50) REFERENCES hotel_rooms(room_id),
    seats_held INTEGER DEFAULT 0,
    rooms_held INTEGER DEFAULT 0,
    status VARCHAR(20) DEFAULT 'HOLD' CHECK (status IN ('HOLD', 'CONFIRMED', 'EXPIRED')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    expires_at TIMESTAMP WITH TIME ZONE NOT NULL
);

-- 4. HO DU LIEU BANH DA TRI THUC DOC QUYEN (DATA FLYWHEEL INTENT LAKE)
CREATE TABLE travel_intents_lake (
    intent_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id VARCHAR(100) NOT NULL,
    origin VARCHAR(50),
    destination VARCHAR(50),
    departure_date DATE,
    preferred_bus_type VARCHAR(50),
    group_size INTEGER DEFAULT 1,
    special_requirements TEXT[],
    sentiment VARCHAR(20) DEFAULT 'NEUTRAL',
    cleaned_timestamp TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
\end{lstlisting}

\subsection{Cấu trúc Bộ sưu tập Vector Qdrant (Hybrid Collection)}
\label{subsec:qdrant_collection}

Để phục vụ tìm kiếm lai BM25 + Dense, Qdrant Collection \texttt{travel\_policies} được cấu hình:
\begin{itemize}
    \item \textbf{Dense Vector:} Kích thước $d = 384$ (sử dụng mô hình \texttt{sentence-transformers/all-MiniLM-L6-v2}), hàm khoảng cách Cosine, chỉ mục đồ thị HNSW với $M = 16$ và $ef\_construct = 100$.
    \item \textbf{Sparse Vector (BM25 Token Index):} Lập chỉ mục các từ vựng hiếm theo tần suất token hóa bằng bộ tách từ tiếng Việt (\texttt{pyvi}).
    \item \textbf{Payload Fields:} \texttt{hotel\_name}, \texttt{room\_type}, \texttt{policy\_category}, \texttt{pet\_allowed}, \texttt{early\_checkin\_fee}.
\end{itemize}

\subsection{Hợp đồng Giao tiếp Dữ liệu Pydantic v2 (API Data Contracts)}
\label{subsec:pydantic_contracts}

Để bảo đảm tính tương thích ngược và ngăn chặn dữ liệu bẩn xâm nhập vào hệ thống, toàn bộ request và response được kiểm thực thông qua Pydantic v2:

\begin{lstlisting}[language=Python, caption={Khuôn mẫu Pydantic v2 Kiểm thực Dữ liệu}]
class ChatRequest(BaseModel):
    session_id: str = Field(..., description="Dinh danh duy nhat cua phien hoi thoai")
    message: str = Field(..., description="Noi dung tin nhan tu nguoi dung")
    channel: str = Field("webchat", description="Kenh: zalo, facebook, webchat")

class ActionDTO(BaseModel):
    type: str = Field(..., description="Loai hanh dong: REDIRECT_OPERATOR, HOLD_SEAT")
    payload: Dict[str, Any] = Field(default_factory=dict)

class ChatResponse(BaseModel):
    session_id: str
    reply: str = Field(..., description="Noi dung phan hoi Markdown chuan xac khong ao giac")
    intent_detected: str = Field(..., description="Y dinh: BUS_ONLY, HOTEL_ONLY, COMBO_INQUIRY")
    actions: List[ActionDTO] = Field(default_factory=list)
    latency_ms: Optional[int] = Field(None, description="Do tre xu ly tinh bang mili-giay")
\end{lstlisting}
